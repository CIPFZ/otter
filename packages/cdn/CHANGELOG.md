# @otter-player/cdn

## 0.1.0-beta.0

### Minor Changes

- cdn: `@otter-player/presets/basic` and `/vod` as ES modules for a page without a build step (jsDelivr: `https://cdn.jsdelivr.net/npm/@otter-player/cdn@<version>/dist/otter-vod/otter-vod.esm.js`), each an entry with its on-demand chunks and its skin's stylesheet.
- First beta of Otter (0.1.0-beta.0): scenario presets, the own HLS and FLV / TS engines with adapter fallbacks, WebCodecs playback, the player UI and skins, React / Vue / Svelte bindings. Release notes and known limitations: `docs/release-notes/0.1.0-beta.0.md`.
