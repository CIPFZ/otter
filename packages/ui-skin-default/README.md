# @otter-player/ui-skin-default

Default skin (CSS only), Otter brand palette.

Part of [Otter](https://github.com/CIPFZ/otter), a pluggable web video player.

```ts
import '@otter-player/ui-skin-default';
```

Or link `node_modules/@otter-player/ui-skin-default/dist/index.css` from the page. The CSS variables it sets are the public ones of `@otter-player/ui-core` (see its README).
