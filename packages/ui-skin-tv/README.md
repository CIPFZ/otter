# @otter-player/ui-skin-tv

TV skin (CSS only): the default skin with a 10-foot layer (type, title-safe area, large focus rings).

Part of [Otter](https://github.com/CIPFZ/otter), a pluggable web video player.

```ts
import '@otter-player/ui-skin-tv';
```

Or link `node_modules/@otter-player/ui-skin-tv/dist/index.css` from the page. The CSS variables it sets are the public ones of `@otter-player/ui-core` (see its README).
