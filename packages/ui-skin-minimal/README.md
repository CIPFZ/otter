# @otter-player/ui-skin-minimal

Minimal skin (CSS only).

Part of [Otter](https://github.com/CIPFZ/otter), a pluggable web video player.

```ts
import '@otter-player/ui-skin-minimal';
```

Or link `node_modules/@otter-player/ui-skin-minimal/dist/index.css` from the page. The CSS variables it sets are the public ones of `@otter-player/ui-core` (see its README).
